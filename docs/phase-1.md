# Phase 1

Foundation for Aura Health AI.

In scope:

- Vite + React + TypeScript app
- Dark sport-tech design system
- Application shell and routes
- Demo dashboard (explicitly labeled)
- Supabase client + env-based config
- PostgreSQL schema with RLS

Out of scope:

- Machine learning
- Anomaly detection
- Diagnosis or clinical prediction
- Wearable APIs
- OpenAI
- Emergency automation
